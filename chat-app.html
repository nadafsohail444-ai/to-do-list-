One-time setup (about 5 minutes)

  1. Go to console.firebase.google.com → Add project (free)
  2. Click the </> (web app) icon to register a web app, copy the firebaseConfig object it gives you
  3. Paste it into this file, replacing the placeholder near the top of the code (search for firebaseConfig)
  4. In the left menu: Build → Authentication → Get started → enable Email/Password
  5. In the left menu: Build → Firestore Database → Create database → start in test mode
  6. Reload this page once you've saved the file
